# Distribuidora El Palmar — Catálogo Web

Primera versión del catálogo web para pedidos por WhatsApp.

- Categorías: **Vinos** y **Licores**
- Búsqueda por producto, marca o familia
- Filtro por categoría, familia y disponibilidad
- Precio de venta en CLP
- Selección de productos para un pedido
- Pedido por WhatsApp usando el número de prueba `+2368802463`

El Excel original contiene 4.759 registros. Esta versión usa los productos de Vinos y Licores que están activos y tienen precio de venta mayor que cero.

**Productos incluidos: 655**

Las imágenes individuales aún no están en el Excel, por lo que esta primera versión usa una presentación visual temporal. Se pueden incorporar fotos reales posteriormente.

## Ejecutar

Requiere Node.js:

```bash
npm install
npm run dev
```
